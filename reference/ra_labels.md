# 2026 Risk Adjustment Labels

2026 Risk Adjustment Labels

## Usage

``` r
ra_labels
```

## Format

### `ra_labels`

A data frame with 783 rows and 5 columns:

- cc:

  Model Weight Categories

- label:

  Model Weights

- model_domain:

  Model Domain

- model_version:

  Model Version

- model_fullname:

  Model Version
