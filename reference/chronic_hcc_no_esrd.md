# HCC is Chronic Without ESRD

HCC is Chronic Without ESRD

## Usage

``` r
chronic_hcc_no_esrd
```

## Format

### `chronic_hcc_no_esrd`

A data frame with 876 rows and 4 columns:

- hcc:

  Hierarchical Condition Codes

- is_chronic:

  HCC is Chronic

- model_version:

  Model Version

- model_domain:

  Model Domain
