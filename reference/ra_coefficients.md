# Risk Adjustment Coefficients

Risk Adjustment Coefficients

## Usage

``` r
ra_coefficients
```

## Format

### `ra_coefficients`

A data frame with 14,764 rows and 5 columns:

- year:

  Year of Release

- coefficient:

  Model Weight Categories

- value:

  Model Weights

- model_domain:

  Model Domain

- model_version:

  Model Version
