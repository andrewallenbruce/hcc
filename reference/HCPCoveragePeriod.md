# A single Health Care Plan coverage period from HD loop

A single Health Care Plan coverage period from HD loop

## Usage

``` r
HCPCoveragePeriod(
  start_date = character(),
  end_date = character(),
  hcp_code = character(),
  hcp_status = character(),
  aid_codes = character()
)
```

## Arguments

- start_date:

  date

- end_date:

  date

- hcp_code:

  code

- hcp_status:

  status

- aid_codes:

  REF\*CE composite

## Value

A object

#> $end_date
