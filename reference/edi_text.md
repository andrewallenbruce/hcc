# Create an EDI Text Object

Create an EDI Text Object

## Usage

``` r
edi_text(x, ...)
```

## Arguments

- x:

  raw X12 text input

- ...:

  dots

## Value

an `<hcc::TextEDI>` S7 object

## Details

Methods for `edi_index`:

- `ANY`

- `character`

- `hcc::TextEDI`

- `list`
