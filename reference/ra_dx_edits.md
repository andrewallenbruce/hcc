# Diagnostic Edit Rules

Diagnostic Edit Rules

## Usage

``` r
ra_dx_edits
```

## Format

### `ra_dx_edits`

A data frame with 107 rows and 9 columns:

- icd10:

  Year of Release

- edit_type:

  Model Weight Categories

- sex:

  Model Weights

- age_min:

  Model Domain

- age_max:

  Model Domain

- action:

  Model Domain

- cc_override:

  Model Domain

- model_name:

  Model Version

- description:

  Model Version
