# HCC is Chronic Without ESRD

HCC is Chronic Without ESRD

## Usage

``` r
hcc_is_chronic_without_esrd_model
```

## Format

### `hcc_is_chronic_without_esrd_model`

A data frame with 876 rows and 4 columns:

- hcc:

  Hierarchical Condition Codes

- is_chronic:

  HCC is Chronic

- model_version:

  Model Version

- model_domain:

  Model Domain
