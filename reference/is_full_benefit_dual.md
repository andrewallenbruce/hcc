# Check if dual eligibility code is Full Benefit Dual

Check if dual eligibility code is Full Benefit Dual

## Usage

``` r
is_full_benefit_dual(dual_code)
```

## Arguments

- dual_code:

  description

## Value

logical

## Examples

``` r
is_full_benefit_dual(c("02", "04", "08"))
#> [1] TRUE TRUE TRUE
```
