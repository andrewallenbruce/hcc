# Risk Adjustment Hierarchies

Risk Adjustment Hierarchies

## Usage

``` r
ra_hierarchies
```

## Format

### `ra_hierarchies`

A data frame with 1,220 rows and 6 columns:

- year:

  Model Year

- cc_parent:

  Parent Condition Code

- cc_child:

  Child Condition Code

- model_domain:

  Model Domain

- model_version:

  Model Version

- model_fullname:

  Model Full Name
