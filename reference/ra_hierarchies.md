# Risk Adjustment Hierarchies

Risk Adjustment Hierarchies

## Usage

``` r
ra_hierarchies
```

## Format

### `ra_hierarchies`

A data frame with 1,220 rows and 6 columns:

- year:

  Year of Release

- cc_parent:

  Model Weight Categories

- cc_child:

  Model Weights

- model_domain:

  Model Domain

- model_version:

  Model Version

- model_fullname:

  Model Version
