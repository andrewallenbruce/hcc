# Create an EDI Parse Object

Create an EDI Parse Object

## Usage

``` r
edi_parse(x, ...)
```

## Arguments

- x:

  raw X12 text input

- ...:

  dots

## Value

an `<hcc::ParsedEDI>` S7 object

## Details

Methods for `edi_index`:

- `ANY`

- `character`

- `hcc::Index820`

- `hcc::Index834`

- `hcc::Index837`

- `hcc::Parsed820`

- `hcc::Parsed834`

- `hcc::Parsed837`

- `list`
