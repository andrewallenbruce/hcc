# Create an EDI Index Object

Create an EDI Index Object

## Usage

``` r
edi_index(x, ...)
```

## Arguments

- x:

  raw X12 text input

- ...:

  dots

## Value

an `<hcc::IndexEDI>` S7 object

## Details

Methods for `edi_index`:

- `ANY`

- `character`

- `hcc::Index820`

- `hcc::Index834`

- `hcc::Text820`

- `hcc::Text834`

- `list`
